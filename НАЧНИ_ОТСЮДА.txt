SENTINEL AI — ИИ-АССИСТЕНТ ДЕЖУРНОГО
===================================

Требование: установлен Docker Desktop и запущен Docker Engine.
Первой сборке требуется доступ к интернету (Docker Hub, npm, PyPI).

WINDOWS POWERSHELL (открыть прямо в папке с проектом):
1. Copy-Item .env.example .env
2. docker compose up --build -d
3. Открыть http://localhost:8080

MAC / LINUX (в папке с проектом):
1. cp .env.example .env
2. docker compose up --build -d
3. Открыть http://localhost:8080

Вход (только локальный демо-режим):
  admin / DemoPass123!
  operator / DemoPass123!

Проверка:
  docker compose ps
  docker compose logs -f --tail=100
  http://localhost:9090/alerts (Prometheus)
  http://localhost:8080/docs (API Swagger)

Порядок демонстрации:
  Симулятор -> High CPU -> 5–25 сек -> Инциденты -> Анализ ->
  Взять в работу -> Принять регламент -> Шаги выполнены вручную ->
  Симулятор -> Сбросить все сигналы -> После исчезновения
  Prometheus alert -> Добавить результат -> Закрыть.

Остановить: docker compose down
ПОЛНОСТЬЮ удалить данные: docker compose down -v

Безопасность: перед публикацией изменить все секреты и пароль в .env.
Описание API, архитектуры, тестирования — README.md.
