SENTINEL AI v1.1 — ОБНОВЛЕНИЕ С СОХРАНЕНИЕМ ДАННЫХ

1) Открой и прочитай ОБНОВЛЕНИЕ_v1.1.md (важно!).
2) Сначала сделай резервную копию PostgreSQL из старой папки проекта:
   docker compose exec db sh -c 'pg_dump -U dutyai -d dutyai -Fc -f /tmp/sentinel_backup.dump'
   docker compose cp db:/tmp/sentinel_backup.dump .\sentinel_backup.dump
3) Распакуй новую папку Sentinel_AI из архива поверх текущей
   C:\Users\ARDOR\Project_B2B\Sentinel_AI
   Согласись на замену исходников, НО НЕ УДАЛЯЙ ПАПКУ.
   Не заменяй свой .env — его в архиве нет.
4) В старой папке Sentinel_AI PowerShell:
   docker compose config --quiet
   docker compose up --build -d
   docker compose ps
5) Открой http://localhost:8080 и сделай Ctrl+F5.

НИКОГДА НЕ ВЫПОЛНЯЙ docker compose down -v или docker volume prune!

Новые возможности: редактирование регламентов (admin), восстановление из архива,
безопасное удаление архивных неиспользуемых регламентов,
скрытие закрытых инцидентов без удаления истории,
более устойчивое восстановление frontend после перезапуска api.

Классификатор в v1.1 по-прежнему rule-based; LLM API — в следующей версии.
