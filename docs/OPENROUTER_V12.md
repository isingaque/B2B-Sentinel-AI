# Sentinel AI v1.2 — бесплатный OpenRouter API

**Статус:** экспериментальный режим в ветке `ai-v1.2`. Стабильная `main` (v1.1) не изменяется.

## Бесплатный ключ

1. Откройте https://openrouter.ai/settings/keys и зарегистрируйтесь.
2. Создайте API-ключ; не передавайте его другим людям и не помещайте в GitHub.
3. Бесплатные модели: https://openrouter.ai/collections/free-models .
4. Используйте `openrouter/free`: этот маршрутизатор выбирает одну из доступных бесплатных моделей. Доступность моделей, качество ответов и лимиты могут меняться. Обычный лимит для бесплатных моделей: 50 запросов в день, 20 в минуту. Для задачи хакатона обычно достаточно.

## Настройка в отдельной папке

Извлеките ZIP ветки `ai-v1.2` в отдельную папку, не смешивая исходники со стабильной v1.1.

В PowerShell из папки v1.2:

```powershell
Copy-Item .env.example .env
```

В файле **`.env`**, не `.env.example`, задайте:

```dotenv
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=YOUR_NEW_OPENROUTER_KEY
OPENROUTER_MODEL=openrouter/free
FRONTEND_PORT=8081
PROMETHEUS_PORT=9091
```

`DEEPSEEK_API_KEY` оставьте пустым. `POSTGRES_PASSWORD`, `JWT_SECRET` и остальные настройки для локального демо можете не менять; при публикации сервиса в интернете требуются отдельные секреты.

## Запуск, не затрагивающий v1.1

Из папки v1.2:

```powershell
docker compose -p sentinel_ai_v12 up --build -d
docker compose -p sentinel_ai_v12 ps
```

Имя Compose-проекта `sentinel_ai_v12` создаёт отдельные контейнеры и тома БД. Порты 8081/9091 позволяют одновременно сохранить работающую v1.1 на 8080/9090.

## Проверка настоящего API-запроса

```powershell
docker compose -p sentinel_ai_v12 exec worker python -m app.openrouter_probe
```

Ожидаемый успешный результат:

```text
PASS: OpenRouter response received and validated
Model route: openrouter:openrouter/free
Category: database | severity: critical
```

Тест отправляет **один реальный запрос**. Ключ не печатается, БД инцидентов не меняется. Ошибка HTTP 401 указывает на ключ, 429 — возможное превышение лимита, 400 — несовместимость параметров/формата с выбранной моделью. Не отправляйте ключ или текст `.env` в переписку.

## Работа системы

При `AI_PROVIDER=openrouter` FastAPI/Celery передаёт через HTTPS только alert name, title и description (с базовой маскировкой секретов), без меток `labels`. Модель должна вернуть JSON с `category`, `severity`, `explanation` и возможными причинами. Backend строго проверяет категории и критичность, вычисляет приоритет и показывает вывод как гипотезу **без выдуманного процента уверенности**.

В случае отказа модели, недостатка лимитов, отсутствия ключа или неверного JSON система автоматически возвращается к прежней локальной классификации. Регламенты берутся только из внутренней базы знаний, никакие команды на серверы не выполняются.

Если пользовательская информация или инциденты конфиденциальны, не включайте внешний API без разрешения. Бесплатные модели могут иметь собственную политику хранения данных.

Для повторной загрузки настроек после правки `.env`:

```powershell
docker compose -p sentinel_ai_v12 up -d --force-recreate api worker scheduler
```

## Что подтверждено, а что нет

GitHub Actions выполняет юнит-тесты работы адаптера и сборку Frontend. Эти тесты не обращаются к реальному OpenRouter. Требуется отдельно подтвердить настоящий ответ модели на вашем компьютере с вашим ключом. Точность реальной LLM не следует оценивать по результатам 91,7%/95,8% старого локального классификатора.

`openrouter/free` может выбирать разные модели для разных запросов, поэтому его вывод и задержки потенциально нестабильны. Для воспроизводимого сравнения можно выбрать конкретный бесплатный ID с `:free` из актуального списка.
