# Оценка классификатора в v1.1

## Что действительно используется

**Текущая классификация**: локальные экспертные правила в `backend/app/ai.py`. Модель LLM через внешний API не вызывается. При наличии меток `category` и `severity` от Prometheus они имеют приоритет — это явное использование подсказки источника, не независимое предсказание. Для теста метки намеренно удалены.

**Поиск регламентов по умолчанию**: хешированные символьные признаки (384D), cosine/lexical similarity, фильтр по категории. Это не нейросетевая модель эмбеддингов. E5 (384D) имеет отдельный экспериментальный, необязательный путь запуска в `docs/EXPERIMENTAL_E5.md`. **Внешний LLM API отложен на v1.2.**

## Результат на 30 октября 2026

| Набор | Кол-во | Category | Severity | Совместная точность |
|---|---:|---:|---:|---:|
| Исходный синтетический | 24 | 24/24 = 100% | 22/24 = 91,7% | 22/24 = **91,7%** |
| Дополнительный синтетический | 48 | 47/48 = 97,9% | 47/48 = 97,9% | 46/48 = **95,8%** |

Совместная точность — доля событий, для которых **одновременно** верно определены category и severity. Priority зависит от severity, но отдельно в наборе не размечен. Тип инцидента в данном MVP представлен категорией и уровнем, а не отдельной детализированной таксономией.

Все примеры **вручную придуманные синтетические**; второй набор был написан отдельно от первого, но не собран независимым поставщиком. Они *не* дают достоверную гарантию 90% на промышленных неизвестных инцидентах. Ориентировочные 95% доверительные интервалы Уилсона для совместной точности: исходный 74,2–97,7%; дополнительный 86,0–98,8% (без поправки на синтетичность и возможную схожесть распределений).

Для промышленного доказательства требования 90% нужны независимо размеченные реальные инциденты из неиспользованного при разработке набора, баланс классов, оценка precision/recall/F1 и разбивка ошибок по категориям и критичности.

## Как воспроизвести

Из корня проекта (при работающем Docker Compose):

```powershell
docker compose cp .\backend\tests api:/srv/tests
docker compose cp .\scripts\evaluate_ai.py api:/srv/evaluate_ai.py
docker compose exec api python /srv/evaluate_ai.py
```

Интерпретируй финальный `PASS` как прохождение **синтетических** тестовых наборов, а не внешнюю сертификацию модели.
